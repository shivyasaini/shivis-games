# Shivi's Games

Every finished browser game Shivi has built, in one place. Open `index.html` for the game room, or jump straight to a game:

| # | Game | What it is |
|---|------|------------|
| 01 | [Dead Hours](games/dead-hours/) | First-person zombie shooter. Hold out wave after wave. |
| 02 | [Emberfall](games/emberfall/) | A knight errant in a dying land. Draw the sword, face the Fallen King. |
| 03 | [Ravenmoor](games/ravenmoor/) | You are the vampire. Every choice is played, across 41 endings. |
| 04 | [Three Lives](games/three-lives/) | Three strangers share one small city. Live all three lives. |
| 05 | [Hook Hero](games/hook-hero/) | Swing-and-fly. Rope the nearest hook, let go, reach the flag. |
| 06 | [Cat Café](games/cat-cafe/) | Make the drinks; the cats carry them to the table. |
| 07 | [Hollow Tide](games/hollow-tide/) | Dive five drowned cities and photograph every landmark. |
| 08 | [The Hollow House](games/the-hollow-house/) | Survival horror in four chapters. |
| 09 | [Oath of the Dead Sun](games/oath-of-the-dead-sun/) | A knight, a forest without a sun, a sword never meant to be found. |
| 10 | [Swordfall](games/swordfall/) | Explore a kingdom on foot or on dragonback. Fight in the Grand Arena. |

Everything is plain HTML/JS. No build step: serve the folder with any static host (Vercel, GitHub Pages) or open `index.html`.

Notes:
- Hook Hero's live "watch a friend" view only works on claude.ai; room codes and ghost codes work anywhere.
- Oath of the Dead Sun is a Godot web export, so it needs to be served over http(s), not opened as a local file.
